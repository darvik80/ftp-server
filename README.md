# FTP Server на разных языках программирования

Один и тот же FTP-сервер реализуется на пяти языках, чтобы сравнивать языки, а
не протокол. Источник истины по протоколу — `docs/` (92 RFC) и `docs/kb/` (сводные
требования по шагам дорожной карты).

## Заглушки

| Реализация | Стек | Точка входа | Сборка |
|---|---|---|---|
| `ftp-server-go/` | Go 1.27 | `main.go` | `go run .` |
| `ftp-server-java/` | Spring Boot 4.2.0, Java 25, Maven | `FtpServerApplication.java` | `mvn spring-boot:run` |
| `ftp-server-cpp/` | C++23, Boost 1.91 (Conan 2), CMake | `src/main.cpp` | `conan install . --build=missing -s compiler.cppstd=23` + `cmake --preset conan-release` |
| `ftp-server-rust/` | Rust, edition 2024 | `src/main.rs` | `cargo run` |
| `ftp-server-python/` | Python ≥ 3.11, стандартная библиотека | `main.py` | `python main.py` |

Команды выполняются из каталога соответствующего подпроекта. Каркасы служат
отправной точкой для реализации общей дорожной карты.

Python-заглушка не открывает сокеты и не реализует FTP: она читает настройки и
печатает область шага 1. Установка пакетов не нужна. Значения порта `2121` и корня
`./ftp-data` заданы в [config.toml](ftp-server-python/config.toml); переменные
`FTP_PORT` и `FTP_ROOT` переопределяют их. Конфигурация загружается рядом с точкой
входа, а относительный путь корня считается от текущего рабочего каталога.
Метаданные и минимальная версия Python указаны в
[pyproject.toml](ftp-server-python/pyproject.toml); Python 3.11 нужен для встроенного
модуля `tomllib`.

## Документация

- [Индекс RFC](docs/index.md) — 92 документа, приоритеты, дорожная карта из 5 шагов.
- [База знаний](docs/kb/README.md) — теги, связи между RFC, сводные требования по шагам.
- Справочники Go-подпроекта: [go-netty](ftp-server-go/docs/ref/go-netty.md) и [gnet](ftp-server-go/docs/ref/gnet.md) — объекты и интерфейсы, иерархии и связи, назначение методов, жизненный цикл и примеры HTTP/SOCKS5. Общих требований протокола не заменяют.
- [Правила проекта](AGENTS.md) — роль агента (советник и документация, код не правит) и команды сборки.

## Дорожная карта (кратко)

1. Ядро протокола — RFC 959, 1123, 854.
2. FEAT/OPTS и сеть — RFC 2389, 2428, 1579.
3. Современные расширения — RFC 3659, 2640.
4. Безопасность — RFC 2577, 2228, 4217.
5. Опционально — RFC 7151, 5797, 1635.
