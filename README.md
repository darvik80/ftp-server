# FTP Server на разных языках программирования

Один и тот же FTP-сервер реализуется на четырёх языках, чтобы сравнивать языки, а
не протокол. Источник истины по протоколу — `docs/` (92 RFC) и `docs/kb/` (сводные
требования по шагам дорожной карты).

## Заглушки

| Реализация | Стек | Точка входа | Сборка |
|---|---|---|---|
| `ftp-server-go/` | Go 1.27 | `main.go` | `go run .` |
| `ftp-server-java/` | Spring Boot 4.2.0, Java 25, Maven | `FtpServerApplication.java` | `mvn spring-boot:run` |
| `ftp-server-cpp/` | C++23, Boost 1.91 (Conan 2), CMake | `src/main.cpp` | `conan install . --build=missing -s compiler.cppstd=23` + `cmake --preset conan-release` |
| `ftp-server-rust/` | Rust, edition 2024 | `src/main.rs` | `cargo run` |

Все заглушки — каркасы: они собираются, печатают scope шага 1 и читают `FTP_PORT` /
`FTP_ROOT`. Протокол в них не реализован.

3. Современные расширения — RFC 3659, 2640.
4. Безопасность — RFC 2577, 2228, 4217.
5. Опционально — RFC 7151, 5797, 1635.
