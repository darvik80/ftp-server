# Связи между RFC: цепочки устаревания и граф зависимостей

Нужен, чтобы не реализовывать отменённую редакцию и понимать, какое расширение на что
надстраивается. Данные взяты из секций `## Отменяет`, `## Отменён`, `## Связанные RFC`
и из текста страниц `docs/rfc-*.md`.

## Нормативное ядро

Единственная сводка «что обязательно» встречается в [RFC 114](../rfc-114.md): все
нормативные требования современного сервера сосредоточены в **RFC 959** и более поздних
Proposed Standard — **2389, 2428, 3659, 2228, 4217, 2640, 7151**. Всё остальное в
каталоге — либо уточнения этого ядра, либо история.

## Явные блоки `Отменяет` / `Отменён`

Только 14 файлов содержат структурное описание отношения. `Отменяет` = заменяет,
`Отменён` = заменён.

⚠️ **Асимметрии графа.** Пары `172 → 265` и `171 → 264` односторонние: у отменяющей
стороны блока `Отменяет` нет. У цепочки `114 → 133 → 141 → 163` структурных блоков нет
вообще — отношения выводятся из дат и boilerplate-фразы, а не из явного указания.
Двусторонние (полные) пары: `959↔765`, `1639↔1545`, `5024↔2204`, `624↔607`.

## Линейные цепочки

```
основная спецификация:
  114 → 172 → 265 → 354 → 542 → 765 → 959  (актуальная редакция)
протокол передачи данных (DTP):
  171 → 264 → 354
комментарии к дизайну:
  607 → 624
ревизия кодов ответов:
  542 → 640 → (актуальная норма — коды RFC 959)
FOOBAR (длинные адреса):
  1545 → 1639 → 2428  (EPRT/EPSV — современное решение)
ODETTE FTP:
  2204 → 5024
«Set Data Type»:
  294 → 959 (TYPE) → 3659 (дополнения)
уточнение print-файлов:
  686 → 691
обновления ранней спецификации:
  354 → 385
```

## Boilerplate исторической группы

Фраза «Исторический документ ранней эволюции FTP. Для реализации современного сервера
нормативной силы не имеет — см. RFC 959 и последующие стандарты» повторяется дословно
в 63 файлах группы «Справочно / история». Это отношение *заменён 959*, а не
индивидуальная оценка: реализовывать содержимое этих страниц не нужно, читать их стоит
только ради истории команд (`MKD`/`RMD`/`PWD` в 775, `STOU` в 949, `MODE C` в 468).

## Граф `## Связанные RFC`

Секция `## Связанные RFC` на страницах RFC — это справочные ссылки, они не означают
обязательности. Плотность связей у ядра:

3659 → 959, 2389, 2640

2577 → 959, 2228, 4217, 1123

4217 → 2228, 959, 2389, 2577
