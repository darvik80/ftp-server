# Темы → RFC (обратный индекс)

Задача обычно приходит как тема («сделать пассивный режим»), а не как номер RFC.
Здесь темы сгруппированы по тому, что реально реализуются в FTP-сервере; нормативные
источники отделены от справочных. Номера `[Pn]` — приоритет, ссылка на шаг — на
[requirements.md](requirements.md).
