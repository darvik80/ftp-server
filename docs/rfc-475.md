# RFC 475 — FTP и сетевая почта

**Оригинал (англ.):** FTP and Network Mail System  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** A.K. Bhushan  
**Приоритет реализации:** 57 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc475.html>

## Аннотация

Связка FTP и почты до SMTP-эпохи.

## Абстракт (перевод)

О FTP и системе сетевой почты.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
