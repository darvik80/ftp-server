# RFC 1639 — Работа FTP с «длинными» адресами (FOOBAR)

**Оригинал (англ.):** FTP Operation Over Big Address Records (FOOBAR)  
**Статус:** Experimental  
**Год:** 1994  
**Авторы:** D. Piscitello  
**Приоритет реализации:** 15 — Низкий приоритет  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc1639.html>

## Аннотация

Экспериментальные LPRT/LPSV для не-IPv4 адресов. На практике вытеснены RFC 2428 (EPRT/EPSV). Реализовывать не нужно, кроме совместимости с музейными клиентами.

## Абстракт (перевод)

RFC задаёт метод назначения адресов, отличных от 32-битных IPv4, через команды Long Port (LPRT) и Long Passive (LPSV) с аргументом, допускающим дополнительные семейства адресов и переменную длину.

## Ключевые положения

Устарело относительно RFC 2428. Исторический интерес; в современном сервере достаточно EPRT/EPSV.
