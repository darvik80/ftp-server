# RFC 7151 — Команда HOST для виртуальных хостов FTP

**Оригинал (англ.):** File Transfer Protocol HOST Command for Virtual Hosts  
**Статус:** Proposed Standard  
**Год:** 2014  
**Авторы:** P. Hethmon, R. McMurray  
**Приоритет реализации:** 11 — Средний приоритет  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc7151.html>

## Аннотация

Аналог Host в HTTP: несколько FTP-сайтов на одном IP. Нужен, если планируете виртуальный хостинг по DNS-имени.

## Абстракт (перевод)

FTP, как определён в RFC 959, не позволяет клиентам и серверам различать несколько DNS-имён, зарегистрированных на один IP-адрес. Документ определяет новую команду FTP, дающую механизм идентификации отдельных виртуальных хостов на FTP-сервере.

## Ключевые положения

### Команда HOST

`HOST <hostname>` отправляется до USER (или после REIN).

Сервер выбирает виртуальный сайт по имени. Ответы: 220 (ок), 504/530/550 при ошибках.

### Когда реализовывать

Только если нужна мультиарендность на одном IP. Иначе можно отложить.
