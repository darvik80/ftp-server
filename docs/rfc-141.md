# RFC 141 — Комментарии к RFC 114

**Оригинал (англ.):** Comments on RFC 114: A File Transfer Protocol  
**Статус:** Unknown  
**Год:** 1971  
**Авторы:** E. Harslem, J.F. Heafner  
**Приоритет реализации:** 82 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc141.html>

## Аннотация

Первые рецензии на исходный FTP.

## Абстракт (перевод)

Комментарии к RFC 114.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
