# RFC 238 — Комментарии к предложениям DTP и FTP

**Оригинал (англ.):** Comments on DTP and FTP proposals  
**Статус:** Unknown  
**Год:** 1971  
**Авторы:** R.T. Braden  
**Приоритет реализации:** 78 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc238.html>

## Аннотация

Ревью ранних черновиков.

## Абстракт (перевод)

Комментарии к предложениям DTP и FTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
