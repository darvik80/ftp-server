# RFC 683 — FTPSRV — расширение Tenex для page-файлов

**Оригинал (англ.):** FTPSRV — Tenex extension for paged files  
**Статус:** Unknown  
**Год:** 1975  
**Авторы:** R. Clements  
**Приоритет реализации:** 39 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc683.html>

## Аннотация

Платформо-специфичное расширение TENEX. Не переносите в общий сервер.

## Абстракт (перевод)

Расширение FTP для page-mode между системами TENEX; надёжность передачи.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
