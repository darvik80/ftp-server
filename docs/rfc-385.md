# RFC 385 — Комментарии к FTP (1972)

**Оригинал (англ.):** Comments on the File Transfer Protocol  
**Статус:** Unknown  
**Год:** 1972  
**Авторы:** A.K. Bhushan  
**Приоритет реализации:** 67 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc385.html>

## Аннотация

Обновления к RFC 354.

## Абстракт (перевод)

Комментарии, обновляющие RFC 354.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
