# RFC 737 — Расширение FTP: XSEN

**Оригинал (англ.):** FTP extension: XSEN  
**Статус:** Unknown  
**Год:** 1977  
**Авторы:** K. Harrenstien  
**Приоритет реализации:** 35 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc737.html>

## Аннотация

Устаревшее почтовое расширение FTP.

## Абстракт (перевод)

Расширение FTP XSEN.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
