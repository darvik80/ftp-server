# RFC 412 — Документация пользовательского FTP

**Оригинал (англ.):** User FTP Documentation  
**Статус:** Unknown  
**Год:** 1972  
**Авторы:** G. Hicks  
**Приоритет реализации:** 66 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc412.html>

## Аннотация

Пользовательская документация раннего клиента.

## Абстракт (перевод)

Документация User-FTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
