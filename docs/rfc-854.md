# RFC 854 — Спецификация протокола Telnet

**Оригинал (англ.):** Telnet Protocol Specification  
**Статус:** Internet Standard  
**Год:** 1983  
**Авторы:** J. Postel, J. Reynolds  
**Приоритет реализации:** 20 — Средний приоритет  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc854.html>

## Аннотация

Не FTP, но управляющий канал FTP использует NVT ASCII и идеи Telnet (включая возможные IAC-последовательности). Нужен для корректной обработки управляющего соединения.

## Абстракт (перевод)

Спецификация протокола Telnet — двунаправленного восьмибитного байт-ориентированного средства связи. FTP опирается на модель NVT.

## Ключевые положения

### Связь с FTP

Управляющее соединение FTP описано как «Telnet-подобное». На практике большинство реализаций:

- строки команд заканчиваются CRLF;
- символы — ASCII/NVT;
- желательно корректно игнорировать или обрабатывать Telnet IAC (0xFF), если клиент их присылает.

Полный Telnet-стек не обязателен, но знание RFC 854 предотвращает тонкие баги.
