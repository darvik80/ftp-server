# RFC 5024 — ODETTE File Transfer Protocol 2.0

**Оригинал (англ.):** ODETTE File Transfer Protocol 2.0  
**Статус:** Informational  
**Год:** 2007  
**Авторы:** I. Friend  
**Приоритет реализации:** 24 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc5024.html>

## Аннотация

Отдельный протокол (OFTP) для EDI в автопроме/индустрии, не IETF FTP. Не путать с RFC 959.

## Абстракт (перевод)

Обновляет ODETTE FTP до версии 2: TLS, шифрование/подписи CMS, сжатие, подписанные квитанции. Для TCP/IP, X.25, ISDN.

## Ключевые положения

Это не классический FTP. К каталогу IETF FTP относится косвенно (похожая предметная область).
