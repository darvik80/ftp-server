# RFC 607 — Комментарии к FTP (ранние)

**Оригинал (англ.):** Comments on the File Transfer Protocol  
**Статус:** Unknown  
**Год:** 1974  
**Авторы:** M. Krilanovich, G. Gregg  
**Приоритет реализации:** 43 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc607.html>

## Аннотация

Заменён RFC 624.

## Абстракт (перевод)

Ранняя версия комментариев; см. RFC 624.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
