# RFC 640 — Пересмотренные коды ответов FTP

**Оригинал (англ.):** Revised FTP reply codes  
**Статус:** Unknown  
**Год:** 1974  
**Авторы:** J. Postel  
**Приоритет реализации:** 18 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc640.html>

## Аннотация

Ранняя систематизация кодов ответов, развитая в RFC 959. Полезно для понимания эволюции xyz-кодов.

## Абстракт (перевод)

Обновляет схему кодов ответов относительно RFC 542.

## Ключевые положения

Исторический шаг к современной системе 1yz–5yz. Актуальная норма — RFC 959.
