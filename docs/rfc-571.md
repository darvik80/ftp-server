# RFC 571 — Проблема FTP на TENEX

**Оригинал (англ.):** TENEX FTP PROBLEM  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** R. Braden  
**Приоритет реализации:** 45 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc571.html>

## Аннотация

Платформенный баг-репорт эпохи ARPANET.

## Абстракт (перевод)

Заметка о проблеме FTP на TENEX.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
