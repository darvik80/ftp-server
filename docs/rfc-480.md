# RFC 480 — Хост-зависимые параметры FTP

**Оригинал (англ.):** Host-dependent FTP parameters  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** J.E. White  
**Приоритет реализации:** 54 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc480.html>

## Аннотация

Параметры, зависящие от ОС хоста.

## Абстракт (перевод)

О хост-зависимых параметрах FTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
