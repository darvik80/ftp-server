**Оригинал (англ.):** Data transfer protocols  
**Статус:** Unknown  
**Год:** 1971  
**Авторы:** V.G. Cerf  
**Приоритет реализации:** 81 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc163.html>

## Аннотация

Обзорный взгляд Cerf на data transfer.

## Абстракт (перевод)

Заметки о протоколах передачи данных.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
