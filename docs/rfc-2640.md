# RFC 2640 — Интернационализация FTP

**Оригинал (англ.):** Internationalization of the File Transfer Protocol  
**Статус:** Proposed Standard  
**Год:** 1999  
**Авторы:** B. Curtin  
**Приоритет реализации:** 10 — Высокий приоритет  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc2640.html>

## Аннотация

UTF-8 для имён файлов и протокола LANG. Без этого кириллические и прочие не-ASCII имена ломаются. Важно для русскоязычных пользователей и современных ОС.

## Абстракт (перевод)

Документ рассматривает интернационализацию (I18n) FTP: поддержку множества наборов символов и языков. Это достигается расширением спецификации FTP и рекомендациями по корректной поддержке интернационализации.

## Ключевые положения

### Ключевые идеи

- Пути и имена должны передаваться в **UTF-8**.
- Возможность объявить `UTF8` в FEAT.
- Команда **LANG** для языка текстовых сообщений сервера (ответы HELP и т.п.).
- Клиент и сервер согласовывают поведение; нельзя предполагать только US-ASCII.

### Для реализации

Храните пути как Unicode/UTF-8 внутри, объявите UTF8 в FEAT, принимайте `OPTS UTF8 ON` (распространённая практика клиентов).

## Что реализовать

- [ ] UTF-8 пути
- [ ] FEAT UTF8
- [ ] LANG
- [ ] OPTS UTF8
