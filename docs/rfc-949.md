# RFC 949 — Команда сохранения с уникальным именем

**Оригинал (англ.):** FTP unique-named store command  
**Статус:** Unknown  
**Год:** 1985  
**Авторы:** M.A. Padlipsky  
**Приоритет реализации:** 30 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc949.html>

## Аннотация

Предложение STOU; вошло в RFC 959. Читать 959.

## Абстракт (перевод)

Предлагает команду FTP, аналогичную STOR, но с уникальным именем файла в текущем каталоге.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
