# RFC 478 — Взаимодействие сервер–сервер FTP — II

**Оригинал (англ.):** FTP server-server interaction — II  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** R.D. Bressler, R. Thomas  
**Приоритет реализации:** 56 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc478.html>

## Аннотация

Продолжение темы third-party transfer.

## Абстракт (перевод)

Вторая заметка о взаимодействии FTP server–server.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
