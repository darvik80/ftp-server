# RFC 2349 — Опции таймаута и размера передачи TFTP

**Оригинал (англ.):** TFTP Timeout Interval and Transfer Size Options  
**Статус:** Draft Standard  
**Год:** 1998  
**Авторы:** G. Malkin, A. Harkin  
**Приоритет реализации:** 88 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc2349.html>

## Аннотация

Ещё опции TFTP.

## Абстракт (перевод)

Две опции TFTP: timeout и tsize.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
