# RFC 751 — Обзор FTP mail и MLFL

**Оригинал (англ.):** Survey of FTP mail and MLFL  
**Статус:** Unknown  
**Год:** 1978  
**Авторы:** P.D. Lebling  
**Приоритет реализации:** 33 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc751.html>

## Аннотация

Исторический обзор почтовых применений FTP. Сегодня почта — SMTP, не FTP.

## Абстракт (перевод)

Обзор использования FTP для почты и MLFL.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
