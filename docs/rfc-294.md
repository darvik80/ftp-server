# RFC 294 — Использование транзакции Set Data Type в FTP

**Оригинал (англ.):** The Use of "Set Data Type" Transaction in File Transfer Protocol  
**Статус:** Unknown  
**Год:** 1972  
**Авторы:** A.K. Bhushan  
**Приоритет реализации:** 72 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc294.html>

## Аннотация

Предок идеи TYPE.

## Абстракт (перевод)

Об использовании Set Data Type в FTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
