# RFC 9141 — Обновление ссылок на FTP-сервис IETF

**Оригинал (англ.):** Updating References to the IETF FTP Service  
**Статус:** Proposed Standard  
**Год:** 2021  
**Авторы:** R. Danyliw  
**Приоритет реализации:** 21 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc9141.html>

## Аннотация

Не о протоколе FTP: замена ftp:// ссылок IETF на HTTPS после вывода из эксплуатации ftp.ietf.org. К реализации сервера отношения не имеет.

## Абстракт (перевод)

FTP-сервис IETF на ftp.ietf.org и связанных хостах выводится из эксплуатации. Документ обновляет FTP-ссылки в затронутых RFC на HTTPS URI.

## Ключевые положения

Административный документ IETF. Не влияет на реализацию FTP-сервера.
