# RFC 250 — Некоторые мысли о передаче файлов

**Оригинал (англ.):** Some thoughts on file transfer  
**Статус:** Unknown  
**Год:** 1971  
**Авторы:** H. Brodie  
**Приоритет реализации:** 77 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc250.html>

## Аннотация

Эссе раннего периода.

## Абстракт (перевод)

Размышления о file transfer.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
