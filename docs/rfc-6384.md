# RFC 6384 — FTP ALG для трансляции IPv6↔IPv4

**Оригинал (англ.):** An FTP Application Layer Gateway (ALG) for IPv6-to-IPv4 Translation  
**Статус:** Proposed Standard  
**Год:** 2011  
**Авторы:** I. van Beijnum  
**Приоритет реализации:** 14 — Низкий приоритет  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc6384.html>

## Аннотация

Про middlebox/ALG, а не про сам FTP-сервер. Полезно понимать, если сервер стоит за трансляторами; реализация ALG обычно не ваша задача.

## Абстракт (перевод)

Документ специфицирует промежуточный узел (ALG), помогающий FTP работать через трансляторы IPv6-to-IPv4, когда клиенты IPv6-only, а серверы — IPv4-only. Надёжнее всего через транслятор проходит расширенный пассивный режим, но его поддерживают не все.

## Ключевые положения

### Вывод для автора сервера

Поддерживайте **EPSV** — это лучший режим через трансляторы. ALG чинит старые PORT/PASV/EPRT сценарии на стороне сети.
