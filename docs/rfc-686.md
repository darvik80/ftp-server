# RFC 686 — «Не трогай, пока работает»

**Оригинал (англ.):** Leaving well enough alone  
**Статус:** Unknown  
**Год:** 1975  
**Авторы:** B. Harvey  
**Приоритет реализации:** 38 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc686.html>

## Аннотация

Сравнение ранних и поздних версий FTP.

## Абстракт (перевод)

Обсуждает различия ранних и более поздних версий FTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
