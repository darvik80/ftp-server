# RFC 487 — Свободная передача файлов

**Оригинал (англ.):** Free file transfer  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** R.D. Bressler  
**Приоритет реализации:** 52 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc487.html>

## Аннотация

Ранние идеи упрощённого обмена файлами.

## Абстракт (перевод)

Предложение по free file transfer.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
