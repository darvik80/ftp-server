# RFC 1415 — Шлюз FTP–FTAM

**Оригинал (англ.):** FTP-FTAM Gateway Specification  
**Статус:** Historic  
**Год:** 1993  
**Авторы:** J. Mindel, R. Slaski  
**Приоритет реализации:** 92 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc1415.html>

## Аннотация

Шлюз между FTP и ISO FTAM. Исторический.

## Абстракт (перевод)

Спецификация прикладного шлюза трансляции FTP↔FTAM.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
