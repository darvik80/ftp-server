# RFC 454 — FTP — анонс встречи и новый черновик

**Оригинал (англ.):** File Transfer Protocol — meeting announcement and a new proposed document  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** A.M. McKenzie  
**Приоритет реализации:** 61 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc454.html>

## Аннотация

Организационный анонс и черновик.

## Абстракт (перевод)

Анонс встречи и предложение нового документа FTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
