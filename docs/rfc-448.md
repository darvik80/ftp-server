# RFC 448 — Print-файлы в FTP

**Оригинал (англ.):** Print files in FTP  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** R.T. Braden  
**Приоритет реализации:** 62 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc448.html>

## Аннотация

Особенности передачи print-файлов.

## Абстракт (перевод)

О print files в FTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
