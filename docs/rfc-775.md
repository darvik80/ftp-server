# RFC 775 — Каталого-ориентированные команды FTP

**Оригинал (англ.):** Directory oriented FTP commands  
**Статус:** Unknown  
**Год:** 1980  
**Авторы:** D. Mankins, D. Franklin, A.D. Owen  
**Приоритет реализации:** 17 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc775.html>

## Аннотация

Истоки MKD/RMD/PWD и родственных идей, позже вошедших в RFC 959. Для реализации читайте 959, не 775.

## Абстракт (перевод)

Исторический документ о командах работы с каталогами в FTP до их включения в основную спецификацию.

## Ключевые положения

Исторический предшественник команд каталогов современного FTP. Нормативная реализация — по RFC 959.
