# RFC 458 — Получение почты через FTP

**Оригинал (англ.):** Mail retrieval via FTP  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** R.D. Bressler, R. Thomas  
**Приоритет реализации:** 60 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc458.html>

## Аннотация

Исторический mail retrieval; сейчас — IMAP/POP/SMTP.

## Абстракт (перевод)

Получение почты посредством FTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
