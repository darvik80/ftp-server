# RFC 1579 — FTP, дружественный к межсетевым экранам

**Оригинал (англ.):** Firewall-Friendly FTP  
**Статус:** Informational  
**Год:** 1994  
**Авторы:** S. Bellovin  
**Приоритет реализации:** 6 — Высокий приоритет  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc1579.html>

## Аннотация

Обосновывает предпочтение пассивного режима: в активном режиме сервер инициирует соединение к клиенту, что ломается firewall'ами. Для сервера — стимул качественно реализовать PASV/EPSV и пул портов данных.

## Абстракт (перевод)

Памятка описывает рекомендуемое изменение поведения FTP-клиентов. Документ носит информационный характер и не задаёт стандарт Интернета.

## Ключевые положения

### Суть

В классическом активном режиме (PORT) сервер подключается *к* клиенту на указанный порт. Межсетевые экраны на стороне клиента часто блокируют такие входящие соединения.

Пассивный режим (PASV/EPSV) инвертирует направление: клиент сам открывает соединение данных к серверу — это проходит через типичные firewall/NAT.

### Для реализации сервера

- PASV/EPSV обязательны на практике.
- Нужен настраиваемый диапазон портов данных.
- Нужно корректно сообщать внешний IP за NAT (или полагаться на EPSV без адреса).

## Что реализовать

- [ ] Приоритет пассивного режима
- [ ] Диапазон портов данных
- [ ] Учёт NAT/firewall при проектировании
