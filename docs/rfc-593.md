# RFC 593 — Изменение графика внедрения Telnet и FTP

**Оригинал (англ.):** Telnet and FTP implementation schedule change  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** A.M. McKenzie, J. Postel  
**Приоритет реализации:** 44 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc593.html>

## Аннотация

Организационное расписание внедрения, не протокол.

## Абстракт (перевод)

Изменение сроков реализации Telnet и FTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
