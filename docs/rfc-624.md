# RFC 624 — Комментарии к FTP

**Оригинал (англ.):** Comments on the File Transfer Protocol  
**Статус:** Unknown  
**Год:** 1974  
**Авторы:** M. Krilanovich, G. Gregg, W. Hathaway, J.E. White  
**Приоритет реализации:** 41 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc624.html>

## Аннотация

Дизайн-заметки эпохи RFC 542. Заменяет RFC 607.

## Абстракт (перевод)

Изменения дизайна и уточнения; заменяет RFC 607.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
