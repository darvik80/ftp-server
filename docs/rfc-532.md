# RFC 532 — Server-FTP в UCSD-CC

**Оригинал (англ.):** UCSD-CC Server-FTP facility  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** R.G. Merryman  
**Приоритет реализации:** 47 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc532.html>

## Аннотация

Описание конкретной реализации, не общий стандарт.

## Абстракт (перевод)

Описание серверного FTP в UCSD-CC.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
