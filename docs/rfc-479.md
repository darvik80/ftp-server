# RFC 479 — Использование FTP журналом NIC

**Оригинал (англ.):** Use of FTP by the NIC Journal  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** J.E. White  
**Приоритет реализации:** 55 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc479.html>

## Аннотация

Прикладной кейс NIC Journal.

## Абстракт (перевод)

Как NIC Journal использовал FTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
