# RFC 5854 — Формат описания загрузок Metalink

**Оригинал (англ.):** The Metalink Download Description Format  
**Статус:** Proposed Standard  
**Год:** 2010  
**Авторы:** A. Bryan, T. Tsujikawa, N. McNab, P. Poeml  
**Приоритет реализации:** 94 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc5854.html>

## Аннотация

XML-описание зеркал и хешей для загрузок. Не расширение FTP-протокола; иногда используется рядом с FTP-URL.

## Абстракт (перевод)

Metalink — XML-формат с зеркалами, хешами и метаданными для надёжной загрузки файлов.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
