# RFC 171 — Протокол передачи данных (1971)

**Оригинал (англ.):** The Data Transfer Protocol  
**Статус:** Unknown  
**Год:** 1971  
**Авторы:** A. Bhushan, B. Braden, W. Crowther, E. Harslem, J. Heafner, A. McKenize, J. Melvin, B. Sundberg, D. Watson, J. White  
**Приоритет реализации:** 80 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc171.html>

## Аннотация

Ранний DTP; заменён последующими RFC.

## Абстракт (перевод)

Ранняя спецификация Data Transfer Protocol.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
