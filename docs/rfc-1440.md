# RFC 1440 — SIFT/UFT: передача по инициативе отправителя

**Оригинал (англ.):** SIFT/UFT: Sender-Initiated/Unsolicited File Transfer  
**Статус:** Experimental  
**Год:** 1993  
**Авторы:** R. Troth  
**Приоритет реализации:** 91 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc1440.html>

## Аннотация

Отдельный экспериментальный протокол «непрошеной» передачи.

## Абстракт (перевод)

Sender-Initiated / Unsolicited File Transfer protocol.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
