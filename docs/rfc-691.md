# RFC 691 — Ещё одна попытка уточнить FTP

**Оригинал (англ.):** One more try on the FTP  
**Статус:** Unknown  
**Год:** 1975  
**Авторы:** B. Harvey  
**Приоритет реализации:** 37 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc691.html>

## Аннотация

Замечания о print-файлах; исторический контекст.

## Абстракт (перевод)

Небольшая ревизия RFC 686 по теме print files.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
