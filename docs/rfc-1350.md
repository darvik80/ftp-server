# RFC 1350 — Протокол TFTP (редакция 2)

**Оригинал (англ.):** The TFTP Protocol (Revision 2)  
**Статус:** Internet Standard  
**Год:** 1992  
**Авторы:** K. Sollins  
**Приоритет реализации:** 85 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc1350.html>

## Аннотация

TFTP — другой протокол (UDP/69), не FTP. В каталоге, потому что часто путают и потому что IETF группирует file transfer.

## Абстракт (перевод)

TFTP — простой протокол передачи файлов на UDP. Не совместим с FTP (RFC 959).

## Ключевые положения

Отдельный протокол. Не реализуйте TFTP вместо FTP. STD 33.
