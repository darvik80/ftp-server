# RFC 2577 — Соображения безопасности FTP

**Оригинал (англ.):** FTP Security Considerations  
**Статус:** Informational  
**Год:** 1999  
**Авторы:** M. Allman, S. Ostermann  
**Приоритет реализации:** 7 — Высокий приоритет  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc2577.html>

## Аннотация

Практические угрозы plain FTP: кража паролей, bounce-атаки через PORT, обход путей (path traversal), злоупотребление анонимным доступом. Обязателен к прочтению до открытия сервера в сеть.

## Абстракт (перевод)

Документ даёт рекомендации системным администраторам и разработчикам FTP-серверов, снижающие типичные проблемы безопасности, связанные с FTP. Информационный характер.

## Ключевые положения

### Основные риски

1. **Пароли открытым текстом** на управляющем соединении.
2. **FTP bounce**: злоумышленник через PORT заставляет сервер подключиться к произвольному хосту/порту.
3. **Path traversal**: `RETR ../../etc/passwd` и подобные.
4. **Анонимный FTP**: запись (STOR) в доступные каталоги → склад вредоносного ПО; утечки листингов.
5. **Информационные утечки** в баннерах SYST/HELP.

### Меры для реализации

- Ограничить PORT только адресом клиента (или отключить PORT).
- Жёсткая нормализация и chroot/jail путей.
- Отдельный пользователь и права для anonymous.
- Запрет записи в anonymous по умолчанию.
- Позже — TLS (RFC 4217) для защиты канала.
