# RFC 264 — Протокол передачи данных (DTP)

**Оригинал (англ.):** The Data Transfer Protocol  
**Статус:** Unknown  
**Год:** 1972  
**Авторы:** A. Bhushan, B. Braden, W. Crowther, E. Harslem, J. Heafner, A. McKenize, B. Sundberg, D. Watson, J. White  
**Приоритет реализации:** 76 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc264.html>

## Аннотация

DTP — основа канала данных; идеи влились в FTP.

## Абстракт (перевод)

Спецификация Data Transfer Protocol.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
