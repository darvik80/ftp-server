# RFC 506 — Проблема именования команд FTP

**Оригинал (англ.):** FTP command naming problem  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** M.A. Padlipsky  
**Приоритет реализации:** 49 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc506.html>

## Аннотация

Дискуссия об именах команд.

## Абстракт (перевод)

Замечания по именованию команд FTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
