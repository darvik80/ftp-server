# RFC 1738 — Унифицированные указатели ресурсов (URL)

**Оригинал (англ.):** Uniform Resource Locators (URL)  
**Статус:** Proposed Standard  
**Год:** 1994  
**Авторы:** T. Berners-Lee, L. Masinter, M. McCahill  
**Приоритет реализации:** 96 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc1738.html>

## Аннотация

Определяет в том числе схему ftp://. Полезно для клиентов и документации; серверу достаточно понимать пути после логина.

## Абстракт (перевод)

Спецификация URL, включая ftp URL.

## Ключевые положения

### ftp URL (идея)

`ftp://user:password@host:port/path`

Часть идей уточнена более новыми URI-документами, но знание схемы нужно для совместимости клиентов.
