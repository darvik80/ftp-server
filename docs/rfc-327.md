# RFC 327 — Заметки воркшопа по Data/File Transfer

**Оригинал (англ.):** Data and File Transfer workshop notes  
**Статус:** Unknown  
**Год:** 1972  
**Авторы:** A.K. Bhushan  
**Приоритет реализации:** 69 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc327.html>

## Аннотация

Протокол встречи, не стандарт.

## Абстракт (перевод)

Заметки воркшопа по протоколам передачи данных и файлов.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
