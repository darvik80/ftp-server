# RFC 309 — Анонс воркшопа Data and File Transfer

**Оригинал (англ.):** Data and File Transfer Workshop Announcement  
**Статус:** Unknown  
**Год:** 1972  
**Авторы:** A.K. Bhushan  
**Приоритет реализации:** 71 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc309.html>

## Аннотация

Организационный анонс.

## Абстракт (перевод)

Объявление о воркшопе.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
