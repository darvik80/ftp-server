# RFC 1545 — FOOBAR (ранняя редакция)

**Оригинал (англ.):** FTP Operation Over Big Address Records (FOOBAR)  
**Статус:** Experimental  
**Год:** 1993  
**Авторы:** D. Piscitello  
**Приоритет реализации:** 16 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc1545.html>

## Аннотация

Ранняя версия FOOBAR, заменена RFC 1639. Только для истории протокола.

## Абстракт (перевод)

Ранняя спецификация длинных адресов в HOST-PORT для FTP. Заменена RFC 1639.

## Ключевые положения

Устарел. См. RFC 1639 и далее RFC 2428.
