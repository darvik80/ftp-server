# RFC 1068 — Фоновая программа передачи файлов (BFTP)

**Оригинал (англ.):** Background File Transfer Program (BFTP)  
**Статус:** Unknown  
**Год:** 1988  
**Авторы:** A.L. DeSchon, R.T. Braden  
**Приоритет реализации:** 93 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc1068.html>

## Аннотация

Сервис фоновых передач на модели third-party FTP.

## Абстракт (перевод)

Описание фонового сервиса передачи файлов на модели FTP third-party.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
