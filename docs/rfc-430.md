# RFC 430 — Комментарии к протоколу передачи файлов

**Оригинал (англ.):** Comments on File Transfer Protocol  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** R.T. Braden  
**Приоритет реализации:** 64 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc430.html>

## Аннотация

Ранние комментарии к черновикам FTP.

## Абстракт (перевод)

Комментарии к File Transfer Protocol.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
