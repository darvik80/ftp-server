# RFC 913 — Простой протокол передачи файлов (SFTP)

**Оригинал (англ.):** Simple File Transfer Protocol  
**Статус:** Historic  
**Год:** 1984  
**Авторы:** M. Lottor  
**Приоритет реализации:** 31 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc913.html>

## Аннотация

Не SSH-SFTP и не RFC 959: отдельный упрощённый протокол между TFTP и FTP. Исторический статус.

## Абстракт (перевод)

Предлагает Simple File Transfer Protocol — мощнее TFTP, проще FTP: доступ, передача, листинг, CWD, rename, delete.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
