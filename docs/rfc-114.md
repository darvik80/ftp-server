# RFC 114 — Протокол передачи файлов (первый RFC)

**Оригинал (англ.):** File Transfer Protocol  
**Статус:** Unknown  
**Год:** 1971  
**Авторы:** A.K. Bhushan  
**Приоритет реализации:** 84 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc114.html>

## Аннотация

Первый RFC про FTP (апрель 1971). Историческая точка отсчёта; к коду современного сервера не применяется.

## Абстракт (перевод)

Исходное предложение File Transfer Protocol для ARPANET.

## Ключевые положения

### Историческое значение

RFC 114 — точка рождения темы FTP в серии RFC. Все нормативные требования современного сервера сосредоточены в RFC 959 и более поздних Proposed Standard (2389, 2428, 3659, 2228, 4217, 2640, 7151).
