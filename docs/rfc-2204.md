# RFC 2204 — ODETTE File Transfer Protocol

**Оригинал (англ.):** ODETTE File Transfer Protocol  
**Статус:** Informational  
**Год:** 1997  
**Авторы:** D. Nash  
**Приоритет реализации:** 25 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc2204.html>

## Аннотация

Предшественник RFC 5024. Отдельный протокол OFTP, не RFC 959.

## Абстракт (перевод)

Описание протокола передачи файлов для EDI между торговыми партнёрами.

## Ключевые положения

Устарел относительно RFC 5024. Не IETF FTP.
