# RFC 3617 — Схема URI и применимость TFTP

**Оригинал (англ.):** URI Scheme and Applicability Statement for the Trivial File Transfer Protocol (TFTP)  
**Статус:** Informational  
**Год:** 2003  
**Авторы:** E. Lear  
**Приоритет реализации:** 89 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc3617.html>

## Аннотация

tftp: URI; сам протокол не рекомендуется из соображений безопасности.

## Абстракт (перевод)

Определяет схему URI для TFTP и обсуждает применимость; от дальнейшего использования в целом отговаривает.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
