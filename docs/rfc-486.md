# RFC 486 — Передача данных: повторный взгляд

**Оригинал (англ.):** Data transfer revisited  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** R.D. Bressler  
**Приоритет реализации:** 53 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc486.html>

## Аннотация

Заметки о data transfer в контексте FTP/DTP.

## Абстракт (перевод)

Повторное рассмотрение передачи данных.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
