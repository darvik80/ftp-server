# RFC 269 — Некоторый опыт передачи файлов

**Оригинал (англ.):** Some Experience with File Transfer  
**Статус:** Unknown  
**Год:** 1971  
**Авторы:** H. Brodie  
**Приоритет реализации:** 74 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc269.html>

## Аннотация

Эксплуатационный опыт раннего FTP.

## Абстракт (перевод)

Опыт использования file transfer.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
