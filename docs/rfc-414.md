# RFC 414 — Статус FTP и дальнейшие комментарии

**Оригинал (англ.):** File Transfer Protocol (FTP) status and further comments  
**Статус:** Unknown  
**Год:** 1972  
**Авторы:** A.K. Bhushan  
**Приоритет реализации:** 65 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc414.html>

## Аннотация

Статусная заметка 1972 года.

## Абстракт (перевод)

Статус FTP и дополнительные комментарии.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
