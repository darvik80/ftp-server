# RFC 2585 — Операционные протоколы PKIX: FTP и HTTP

**Оригинал (англ.):** Internet X.509 Public Key Infrastructure Operational Protocols: FTP and HTTP  
**Статус:** Proposed Standard  
**Год:** 1999  
**Авторы:** R. Housley, P. Hoffman  
**Приоритет реализации:** 22 — Низкий приоритет  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc2585.html>

## Аннотация

Как раздавать сертификаты и CRL через FTP/HTTP. Не расширение протокола FTP; может понадобиться, если сервер — репозиторий PKI.

## Абстракт (перевод)

Определяет соглашения по использованию FTP и HTTP для получения сертификатов и списков отзыва (CRL) из репозиториев PKI.

## Ключевые положения

Прикладное использование FTP как транспорта для PKI-объектов. Обычному файловому FTP-серверу не требуется.
