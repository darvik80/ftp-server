# RFC 614 — Ответ на RFC 607

**Оригинал (англ.):** Response to RFC 607: "Comments on the File Transfer Protocol"  
**Статус:** Unknown  
**Год:** 1974  
**Авторы:** K.T. Pogran, N. Neigus  
**Приоритет реализации:** 42 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc614.html>

## Аннотация

Дискуссия по комментариям к раннему FTP.

## Абстракт (перевод)

Ответ на RFC 607 в контексте RFC 542/640.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
