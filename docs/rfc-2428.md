# RFC 2428 — Расширения FTP для IPv6 и NAT

**Оригинал (англ.):** FTP Extensions for IPv6 and NATs  
**Статус:** Proposed Standard  
**Год:** 1998  
**Авторы:** M. Allman, S. Ostermann, C. Metz  
**Приоритет реализации:** 4 — Критично  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc2428.html>

## Аннотация

Заменяет IPv4-завязанные PORT/PASV на EPRT/EPSV. Нужен для IPv6 и сильно упрощает жизнь за NAT. Без EPSV современные стеки и dual-stack окружения ломаются.

## Абстракт (перевод)

Документ определяет расширения FTP, позволяющие протоколу работать поверх IPv4 и IPv6.

## Ключевые положения

### Проблема

Формат `PORT h1,h2,h3,h4,p1,p2` и ответ PASV рассчитаны только на IPv4 (32-битный адрес).

### Новые команды

#### EPRT
`EPRT |<af>|<addr>|<port>|`

- af=1 — IPv4, af=2 — IPv6
- Пример: `EPRT |2|2001:db8::1|5282|`

#### EPSV
Запрос расширенного пассивного режима. Ответ:

```
229 Entering Extended Passive Mode (|||6446|)
```

Адрес обычно подразумевается тем же, что у управляющего соединения — это удобно за NAT.

#### Код 522
Если запрошенное семейство адресов не поддерживается.

### Для реализации

Минимум: **EPSV** (даже только для IPv4) + объявление в FEAT. EPRT — для активного режима в dual-stack.
