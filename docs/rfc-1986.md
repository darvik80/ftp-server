# RFC 1986 — Эксперименты ETFTP для радиоканалов

**Оригинал (англ.):** Experiments with a Simple File Transfer Protocol for Radio Links using ETFTP  
**Статус:** Experimental  
**Год:** 1996  
**Авторы:** W. Polites, W. Wollman, D. Woo, R. Langan  
**Приоритет реализации:** 90 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc1986.html>

## Аннотация

Экспериментальный ETFTP/NETBLT, не классический FTP.

## Абстракт (перевод)

Enhanced TFTP как экспериментальная реализация NETBLT для радиосвязи.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
