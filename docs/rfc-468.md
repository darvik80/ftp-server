# RFC 468 — Сжатие данных в FTP

**Оригинал (англ.):** FTP data compression  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** R.T. Braden  
**Приоритет реализации:** 58 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc468.html>

## Аннотация

Ранние идеи сжатия; в 959 есть MODE C, на практике редко.

## Абстракт (перевод)

Заметки о сжатии данных в FTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
