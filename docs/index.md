# FTP RFC — документация

Документация по RFC, связанным с File Transfer Protocol. Это не сайт:
весь материал — Markdown-файлы этого каталога, удобные для чтения в редакторе, на
Git-хостинге и офлайн.

Документы отсортированы по важности для реализации FTP-сервера: у каждого RFC есть
аннотация (какую задачу закрывает), перевод ключевых положений и чек-лист «что
реализовать». Начните с дорожной карты и [RFC 959](rfc-959.md).

## Дорожная карта реализации

| Шаг | Тема | RFC | Цель |
|---|---|---|---|
| 1 | **Ядро протокола** | [RFC 959](rfc-959.md), [RFC 1123](rfc-1123.md), [RFC 854](rfc-854.md) | Сессия, команды, PORT/PASV, TYPE A/I, RETR/STOR, каталоги, коды ответов |
| 2 | **Обнаружение возможностей и сеть** | [RFC 2389](rfc-2389.md), [RFC 2428](rfc-2428.md), [RFC 1579](rfc-1579.md) | FEAT/OPTS, EPSV/EPRT, пассивный режим за NAT/firewall |
| 3 | **Современные расширения** | [RFC 3659](rfc-3659.md), [RFC 2640](rfc-2640.md) | SIZE/MDTM/MLST/REST STREAM, UTF-8 имена |
| 4 | **Безопасность** | [RFC 2577](rfc-2577.md), [RFC 2228](rfc-2228.md), [RFC 4217](rfc-4217.md) | Анти-bounce, path safety, затем FTPS (AUTH TLS) |
| 5 | **Опционально** | [RFC 7151](rfc-7151.md), [RFC 5797](rfc-5797.md), [RFC 1635](rfc-1635.md) | Виртуальные хосты, реестр IANA, anonymous-политика |
