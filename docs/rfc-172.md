# RFC 172 — Протокол передачи файлов (июнь 1971)

**Оригинал (англ.):** The File Transfer Protocol  
**Статус:** Unknown  
**Год:** 1971  
**Авторы:** A. Bhushan, B. Braden, W. Crowther, E. Harslem, J. Heafner, A. McKenzie, J. Melvin, B. Sundberg, D. Watson, J. White  
**Приоритет реализации:** 79 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc172.html>

## Аннотация

Одна из первых цельных спецификаций FTP.

## Абстракт (перевод)

Ранняя спецификация The File Transfer Protocol.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
