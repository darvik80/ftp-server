# RFC 310 — Ещё один взгляд на протоколы передачи данных и файлов

**Оригинал (англ.):** Another Look at Data and File Transfer Protocols  
**Статус:** Unknown  
**Год:** 1972  
**Авторы:** A.K. Bhushan  
**Приоритет реализации:** 70 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc310.html>

## Аннотация

Аналитическая заметка эпохи формирования FTP/DTP.

## Абстракт (перевод)

Повторный анализ протоколов Data и File Transfer.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
