# RFC 281 — Предлагаемое дополнение к FTP

**Оригинал (англ.):** Suggested addition to File Transfer Protocol  
**Статус:** Unknown  
**Год:** 1971  
**Авторы:** A.M. McKenzie  
**Приоритет реализации:** 73 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc281.html>

## Аннотация

Раннее предложение расширения.

## Абстракт (перевод)

Предложение дополнения к FTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
