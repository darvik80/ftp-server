# RFC 505 — Два решения проблемы доступа при передаче файлов

**Оригинал (англ.):** Two solutions to a file transfer access problem  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** M.A. Padlipsky  
**Приоритет реализации:** 50 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc505.html>

## Аннотация

Ранние идеи контроля доступа.

## Абстракт (перевод)

Два подхода к проблеме доступа при file transfer.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
