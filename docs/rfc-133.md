# RFC 133 — Передача файлов и восстановление после ошибок

**Оригинал (англ.):** File Transfer and Error Recovery  
**Статус:** Unknown  
**Год:** 1971  
**Авторы:** R.L. Sundberg  
**Приоритет реализации:** 83 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc133.html>

## Аннотация

Ранние идеи надёжности и recovery.

## Абстракт (перевод)

File Transfer and Error Recovery.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
