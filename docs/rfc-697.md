# RFC 697 — Команда CWD в FTP

**Оригинал (англ.):** CWD command of FTP  
**Статус:** Unknown  
**Год:** 1975  
**Авторы:** J. Lieb  
**Приоритет реализации:** 36 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc697.html>

## Аннотация

Раннее обсуждение CWD и доступа к каталогам «только файлы».

## Абстракт (перевод)

Обсуждает доступ FTP login к каталогам типа files-only.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
