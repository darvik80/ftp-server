# RFC 354 — Протокол передачи файлов (1972)

**Оригинал (англ.):** File Transfer Protocol  
**Статус:** Unknown  
**Год:** 1972  
**Авторы:** A.K. Bhushan  
**Приоритет реализации:** 68 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc354.html>

## Аннотация

Крупная ранняя спецификация; заменена RFC 542.

## Абстракт (перевод)

Спецификация FTP 1972 года.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
