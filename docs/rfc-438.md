# RFC 438 — Взаимодействие сервер–сервер FTP

**Оригинал (англ.):** FTP server-server interaction  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** R. Thomas, R. Clements  
**Приоритет реализации:** 63 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc438.html>

## Аннотация

Third-party transfer: один клиент управляет двумя серверами.

## Абстракт (перевод)

Взаимодействие FTP server–server.

## Ключевые положения

### Server-to-server

Клиент устанавливает управляющие соединения с двумя серверами и устраивает передачу данных напрямую между ними (PORT указывает на другой сервер).

В современном интернете это часто запрещают из-за bounce-атак (см. RFC 2577).
