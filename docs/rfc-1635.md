# RFC 1635 — Как пользоваться анонимным FTP

**Оригинал (англ.):** How to Use Anonymous FTP  
**Статус:** Informational  
**Год:** 1994  
**Авторы:** P. Deutsch, A. Emtage, A. Marine  
**Приоритет реализации:** 13 — Средний приоритет  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc1635.html>

## Аннотация

Описывает ожидания пользователей от anonymous FTP (логин anonymous/ftp, пароль-email). Полезно для политики гостевого доступа, не для протокола как такового.

## Абстракт (перевод)

Документ даёт новичку информацию об использовании FTP: что такое FTP, anonymous FTP и архивный сайт anonymous FTP. Информационный характер, не стандарт.

## Ключевые положения

### Практика anonymous

- Пользователь: `anonymous` или `ftp`
- Пароль: часто адрес электронной почты (или произвольная строка)
- Обычно только чтение из выделенного дерева

### Для сервера

Поддержите отдельный путь/chroot для anonymous и политику из RFC 2577.
