# RFC 501 — Прояснение «свободной» передачи файлов

**Оригинал (англ.):** Un-muddling "free file transfer"  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** K.T. Pogran  
**Приоритет реализации:** 51 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc501.html>

## Аннотация

Уточнение идеи free file transfer.

## Абстракт (перевод)

Прояснение концепции free file transfer.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
