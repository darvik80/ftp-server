# RFC 847 — Сводка опросов Smallberg (Telnet/FTP/SMTP)

**Оригинал (англ.):** Summary of Smallberg surveys  
**Статус:** Unknown  
**Год:** 1983  
**Авторы:** A. Westine, D. Smallberg, J. Postel  
**Приоритет реализации:** 32 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc847.html>

## Аннотация

Статистика доступности серверов в 1982–83. Не спецификация.

## Абстракт (перевод)

Сводка опросов серверов Telnet, FTP и SMTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
