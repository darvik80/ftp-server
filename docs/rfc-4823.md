# RFC 4823 — FTP как транспорт для безопасного B2B-обмена

**Оригинал (англ.):** FTP Transport for Secure Peer-to-Peer Business Data Interchange over the Internet  
**Статус:** Informational  
**Год:** 2007  
**Авторы:** T. Harding, R. Scott  
**Приоритет реализации:** 23 — Низкий приоритет  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc4823.html>

## Аннотация

Профиль обмена бизнес-документами (EDI/XML) через FTP + S/MIME. Не меняет сам FTP; прикладной уровень поверх.

## Абстракт (перевод)

Описывает, как безопасно обмениваться структурированными бизнес-данными через FTP с MIME/S/MIME упаковкой и подписанными квитанциями.

## Ключевые положения

Прикладной профиль. Реализация FTP-сервера не требует специальной поддержки сверх обычной передачи файлов.
