# RFC 5797 — Реестр команд и расширений FTP

**Оригинал (англ.):** FTP Command and Extension Registry  
**Статус:** Proposed Standard  
**Год:** 2010  
**Авторы:** J. Klensin, A. Hoenes  
**Приоритет реализации:** 12 — Средний приоритет  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc5797.html>

## Аннотация

Не новый протокол, а IANA-реестр имён команд и FEAT-фич. Нужен, чтобы не изобретать конфликтующие имена расширений и сверяться с официальным списком.

## Абстракт (перевод)

Каждая версия спецификации FTP добавляла команды; RFC 2389 ввёл согласование расширений. Число расширений растёт. Документ учреждает реестр IANA имён команд и возможностей FTP, чтобы снизить риск конфликтов имён.

## Ключевые положения

### Для реализации

Перед добавлением собственной команды/фичи проверьте реестр IANA. Сам по себе RFC не требует кода в сервере, кроме корректных имён в FEAT.
