# RFC 2348 — Опция размера блока TFTP

**Оригинал (англ.):** TFTP Blocksize Option  
**Статус:** Draft Standard  
**Год:** 1998  
**Авторы:** G. Malkin, A. Harkin  
**Приоритет реализации:** 87 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc2348.html>

## Аннотация

Опция blksize для TFTP.

## Абстракт (перевод)

Согласование размера блока TFTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
