# RFC 542 — Протокол передачи файлов (1973)

**Оригинал (англ.):** File Transfer Protocol  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** N. Neigus  
**Приоритет реализации:** 46 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc542.html>

## Аннотация

Крупная ранняя спецификация; цепочка → 765 → 959.

## Абстракт (перевод)

Спецификация FTP 1973 года, позже заменена RFC 765.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
