# RFC 520 — Предложение File Access Protocol

**Оригинал (англ.):** Memo to FTP group: Proposal for File Access Protocol  
**Статус:** Unknown  
**Год:** 1973  
**Авторы:** J.D. Day  
**Приоритет реализации:** 48 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc520.html>

## Аннотация

Идеи доступа к файлам сверх простой передачи.

## Абстракт (перевод)

Памятка группе FTP с предложением протокола доступа к файлам.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
