# RFC 630 — Коды ошибок FTP для надёжной почты

**Оригинал (англ.):** FTP error code usage for more reliable mail service  
**Статус:** Unknown  
**Год:** 1974  
**Авторы:** J. Sussman  
**Приоритет реализации:** 40 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc630.html>

## Аннотация

Историческое использование FTP как транспорта почты TENEX.

## Абстракт (перевод)

Описывает использование кодов ответов FTP в обработке почты TENEX.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
