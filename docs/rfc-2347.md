# RFC 2347 — Расширение опций TFTP

**Оригинал (англ.):** TFTP Option Extension  
**Статус:** Draft Standard  
**Год:** 1998  
**Авторы:** G. Malkin, A. Harkin  
**Приоритет реализации:** 86 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc2347.html>

## Аннотация

Опции TFTP, не FTP.

## Абстракт (перевод)

Согласование опций до передачи в TFTP.

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
