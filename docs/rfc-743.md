# RFC 743 — Расширение FTP: XRSQ/XRCP

**Оригинал (англ.):** FTP extension: XRSQ/XRCP  
**Статус:** Unknown  
**Год:** 1977  
**Авторы:** K. Harrenstien  
**Приоритет реализации:** 34 — Справочно / история  
**Официальный текст:** <https://www.rfc-editor.org/rfc/rfc743.html>

## Аннотация

Устаревшие почтовые расширения FTP.

## Абстракт (перевод)

Расширения FTP XRSQ/XRCP (исторические, почтовые).

## Ключевые положения

Исторический документ ранней эволюции FTP. Для реализации современного сервера нормативной силы не имеет — см. RFC 959 и последующие стандарты.
